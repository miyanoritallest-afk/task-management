# 機能一覧・ユースケース

## 1. 機能一覧（フェーズ別）

| フェーズ | 機能 | 内容 |
|---------|------|------|
| 1 | カード追加 | タイトルと優先度を入力して追加 |
| 1 | カード削除 | カードをクリックして詳細モーダルを開き「削除する」ボタンで削除 |
| 1 | カラム間移動 | ドラッグ&ドロップまたは詳細モーダルから移動 |
| 1 | 優先度設定 | カード追加時・詳細編集時に高/中/低/なしを設定。カード左ボーダーとバッジで色分け表示 |
| 1 | タイトル編集 | カードをシングルクリックして詳細モーダルでタイトルを編集 |
| 1 | カラムソート | カラム単位で優先度順・期限順に並び替え（ソート解除で手動順に戻る） |
| 1 | データ保存 | Supabase（PostgreSQL）にリアルタイム保存 |
| 2 | 説明文 | カードに詳細テキストを追加 |
| 2 | 期限設定 | 締切日を設定・表示 |
| 3 | 並び替え | カラム内の順番を変更 |
| 3 | ドラッグ&ドロップ | カードをドラッグで移動 |
| 4 | 複数ボード | ボードを複数作成・切り替え |
| 4 | カード色付け | カードに色をつける |

---

## 2. 開発フェーズ

### フェーズ1（基本機能）
- カードの追加（タイトル＋優先度・説明文・期限日をモーダルで入力）・削除
- カラム間の移動（ドラッグ&ドロップ）
- カード詳細モーダルでのタイトル・説明文・期限日・優先度編集（シングルクリックで開く）
- 優先度設定（高/中/低/なし）とカード上への色分け表示
- カラム単位のソート（優先度順・期限順、セレクトボックスで切り替え）
- PostgreSQLへの保存（Spring Boot REST API経由）

### フェーズ2（カード詳細）
- カードへの説明文追加
- 締切日の設定と表示

### フェーズ3（操作性向上）
- カラム内の並び替え
- ドラッグ&ドロップでの移動

### フェーズ4（拡張機能）
- 複数ボードの作成・切り替え
- カードへの色付け

## 4. ユースケース詳細

### UC-01: カードを追加する（優先度指定）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカラムにカードをタイトルと優先度を指定して新規追加する |
| **事前条件** | ボード画面が表示されている |
| **基本フロー** | 1. 任意のカラムの「+ カードを追加」ボタンを押す<br>2. テキスト入力欄と優先度選択（高/中/低/なし）が表示される<br>3. タイトルを入力し、任意で優先度を選択する<br>4. 追加ボタンを押す（またはEnterキー）<br>5. カードがカラム末尾に追加され、DBに保存される |
| **代替フロー** | 3a. Escキーまたは「×」ボタンを押す → 入力欄が閉じ、カードは追加されない |
| **事後条件** | 入力したタイトル・優先度のカードがカラムに表示される |

### UC-02: カードを削除する

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカードを削除する |
| **事前条件** | 削除対象のカードが存在する |
| **基本フロー** | 1. 削除したいカードをクリックしてカード詳細モーダルを開く<br>2. 「削除する」ボタンを押す<br>3. カードが削除され、DBから削除される |
| **代替フロー** | なし（確認ダイアログなし） |
| **事後条件** | 対象カードがカラムから消える |

### UC-03: カードを別のカラムに移動する

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがドラッグ&ドロップでカードを別のカラムに移動する |
| **事前条件** | 移動対象のカードが存在する |
| **基本フロー** | 1. カードをつかんで別のカラムにドラッグする<br>2. ドロップするとカードが移動先のカラムに表示される<br>3. DBのcolumn_idとpositionが更新される |
| **代替フロー** | 1a. カードをもとのカラムにドロップ → 移動しない |
| **事後条件** | カードが移動先のカラムに表示される |

### UC-04: カードの詳細を編集する（フェーズ2）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカードのタイトル・説明文・期限を編集する |
| **事前条件** | 編集対象のカードが存在する |
| **基本フロー** | 1. カードのタイトル部分をクリックする<br>2. カード詳細モーダルが表示される<br>3. タイトル・説明文・期限日を編集する<br>4. 「保存」ボタンを押す<br>5. 変更内容がDBに保存され、カードの表示が更新される |
| **代替フロー** | 4a. 「×」ボタンまたはモーダル外をクリック → 変更を破棄してモーダルを閉じる |
| **事後条件** | 編集内容がカードに反映される |

### UC-05: カードに期限を設定する（フェーズ2）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカードに締切日を設定する |
| **事前条件** | カード詳細モーダルが表示されている |
| **基本フロー** | 1. 日付ピッカーで締切日を選択する<br>2. 「保存」ボタンを押す<br>3. カードに期限日が表示される |
| **代替フロー** | 3a. 期限日が過去の日付の場合、カード上に赤字で表示される |
| **事後条件** | カードに期限日が表示される |

### UC-06: カードをドラッグ&ドロップで移動する（フェーズ3）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカードをドラッグして別のカラムまたは同カラム内の別位置に移動する |
| **事前条件** | 移動対象のカードが存在する |
| **基本フロー** | 1. カードをつかむ（マウスボタンを押したまま）<br>2. 移動先にドラッグする<br>3. ドロップする<br>4. カードが移動先に表示され、DBのcolumn_idとpositionが更新される |
| **代替フロー** | 3a. カードをもとの位置にドロップ → 移動しない |
| **事後条件** | カードが指定した位置に表示される |

### UC-07: カラム内でカードを並び替える（フェーズ3）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーが同一カラム内でカードの順序を変更する |
| **事前条件** | 同一カラムに2枚以上のカードが存在する |
| **基本フロー** | 1. カードをドラッグして同カラム内の別位置にドロップする<br>2. カードの順序が変わり、DBのpositionが更新される |
| **代替フロー** | なし |
| **事後条件** | カラム内のカード順序が変更される |

### UC-08: ボードを新規作成する（フェーズ4）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーが新しいボードを作成する |
| **事前条件** | ボード画面が表示されている |
| **基本フロー** | 1. 「新しいボードを作成」ボタンを押す<br>2. ボード名を入力する<br>3. 作成ボタンを押す<br>4. 新しいボードが作成され、DBに保存される<br>5. 作成したボードに切り替わる |
| **代替フロー** | 2a. ボード名が空の場合、作成ボタンを非活性にする |
| **事後条件** | 新しいボードが表示される |

### UC-09: ボードを切り替える（フェーズ4）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーが既存のボードを選択して切り替える |
| **事前条件** | 2つ以上のボードが存在する |
| **基本フロー** | 1. ヘッダーのボード選択メニューを開く<br>2. 切り替えたいボードを選択する<br>3. 選択したボードのカラムとカードが表示される |
| **代替フロー** | なし |
| **事後条件** | 選択したボードの内容が表示される |

### UC-10: カードに色をつける（フェーズ4）

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカードに色を設定してラベル付けする |
| **事前条件** | カード詳細モーダルが表示されている |
| **基本フロー** | 1. カラーピッカーで色を選択する<br>2. 「保存」ボタンを押す<br>3. カードが選択した色で表示される |
| **代替フロー** | 1a. 色をクリアする → カードがデフォルト色に戻る |
| **事後条件** | カードが指定した色で表示される |

### UC-12: カードの優先度を設定する

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカードに優先度（高/中/低/なし）を設定する |
| **事前条件** | カードが存在する |
| **基本フロー（追加時）** | 1. 「+ カードを追加」を押してカード追加モーダルを開く<br>2. 優先度セレクトボックス（高 / 中 / 低 / なし）で優先度を選択する<br>3. 「追加する」ボタンを押す<br>4. 選択した優先度でカードが追加される |
| **基本フロー（編集時）** | 1. カードタイトルをクリックして詳細モーダルを開く<br>2. 優先度セレクタで値を変更する<br>3. 「保存」ボタンを押す |
| **表示仕様** | 優先度に応じてカード左ボーダー色（赤/黄/緑/グレー）とバッジ（🔴高 / 🟡中 / 🟢低）が変わる |
| **事後条件** | カードに設定した優先度が表示される |

### UC-13: カラムのカードをソートする

| 項目 | 内容 |
|------|------|
| **概要** | ユーザーがカラム単位でカードを優先度順または期限順に並び替える |
| **事前条件** | ソート対象のカラムにカードが存在する |
| **基本フロー** | 1. カラムヘッダーのソートセレクトボックスで「優先度順」または「期限順」を選択する<br>2. カードが選択した順序で並び替えられる |
| **代替フロー** | 1a. セレクトボックスで「手動」を選択する → ソートが解除され手動順（position順）に戻る |
| **制約** | ソート中もドラッグ&ドロップは動作するが、ソートが再適用されるため見た目は手動順にならない |
| **事後条件** | カードが指定した順序で表示される |
